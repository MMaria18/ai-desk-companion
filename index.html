AI Desk Companion

An intelligent voice-interactive embedded system designed for seamless human–machine communication.

Firmware: Xiaozhi · Server: xiaozhi.me

Bill of Materials

MCU ESP32-S3 Zero Dual-core, Wi-Fi, USB-C
MIC INMP441 I2S digital, GPIO4/5/6
AMP MAX98357A I2S Class-D, GPIO7/8/9
DISP 0.96" OLED SSD1306, I2C, GPIO10/11

Device Capabilities

🎙
Voice Conversation
Real-time speech interaction using the INMP441 microphone
🌐
Multilingual AI
Ask questions, translate, summarize, and chat naturally
📶
Wi-Fi Connected
Automatically reconnects to the configured network
🕐
Standby Mode
Shows the clock when idle, wakes with the BOOT button
